# SDR Web应用 · 云端部署指南

## 选购腾讯云轻量服务器

### 1. 购买入口
- 登录 https://console.cloud.tencent.com/lighthouse
- 点"新建"创建实例

### 2. 推荐配置（50-60元/月）
| 项目 | 选择 |
|------|------|
| 地域 | 成都（离BD最近） |
| 镜像 | Ubuntu 22.04 LTS |
| 实例 | 1核2G · 50元/月 |
| 系统盘 | 40GB SSD（默认） |
| 流量 | 200GB/月（默认够用） |

### 3. 设置密码
- 购买时设置root密码（记好，SSH要用）

### 4. 开放端口
购买后在控制台 → 防火墙 → 添加规则：
- TCP 5000端口（Flask服务）
- TCP 22端口（SSH，默认已开）

### 5. 拿到公网IP
实例列表里能看到公网IP（形如 43.xxx.xxx.xxx）

## 部署步骤（5分钟）

### 方式1：用SSH命令部署（推荐）

买完服务器后，告诉我：
- **公网IP**
- **root密码**

我会通过SSH连上去，自动完成：
1. 上传应用代码
2. 安装Python和Flask
3. 初始化数据库
4. 配置开机自启服务
5. 启动并验证

### 方式2：手动部署（如果你自己操作）

SSH登录服务器后执行：

```bash
# 1. 装Python和git
apt update && apt install -y python3 python3-pip python3-venv git

# 2. 把 sdr_web 整个目录上传到服务器 /opt/sdr_web
#    （用scp或宝塔面板上传）

# 3. 进入目录，运行部署脚本
cd /opt/sdr_web
bash deploy.sh
```

部署完后访问 `http://你的公网IP:5000/`

## 常见问题

**Q: BD访问不了？**
A: 检查腾讯云控制台防火墙是否开放5000端口

**Q: 服务挂了怎么办？**
A: SSH登录后执行 `systemctl restart sdr-web`

**Q: 数据会丢吗？**
A: SQLite数据库在 `/opt/sdr_web/sdr.db`，建议每周备份：
   `cp /opt/sdr_web/sdr.db /opt/sdr_web/sdr_backup_$(date +%Y%m%d).db`

**Q: 以后怎么更新客户数据？**
A: 重新从秦丝CRM抓取 → 替换 chengdu_final_enriched.json → 运行 init_db.py
