- **列表API手机号脱敏**: `189****5261` 格式，无法直接获取完整号
- **Vue row数据**: 表格tr元素的`__vue__.row`属性包含完整客户数据，含userId/cid/sysType等ID字段
- **详情API端点**: `/console/crm/user/v2/userExtendInfo.ac` (POST+JSON, 参数: `{cid, sysType}`)
- **详情API返回**: `object.userExtendInfo.cellphone` = 完整手机号（100%覆盖）
- **详情API返回**: `object.userExtendInfo.payAmount` = 真实付费金额（100%覆盖）
- **详情API返回**: `object.userProfileInfoVO` / `object.userInfoVO` / `object.userPromotionInfo` = 画像字段
- **getUserGoodsInfo.ac**: 404不存在（v2路径下）
- **getUserInfoMoreDate.ac**: 404不存在（v2路径下）
- **Element UI表格**: 有固定列和滚动列两个table元素，Vue row按userId去重可避免重复
